# 动作、图集与触发边界

下表是图集状态语义，**不是已验证的客户端事件绑定**。

| 行 | 名称 | 帧数 | 设计与用途 |
|---|---|---:|---|
|0|idle|6|轻微下沉、眨眼，平静待机|
|1|running-right|8|向右的方向移动|
|2|running-left|8|向左的方向移动|
|3|waving|4|短侧肢挥动，打招呼|
|4|jumping|5|双节拍轻跳，回到基线|
|5|failed|8|克制的摇晃，失败反应|
|6|waiting|6|期待回应的短肢姿态、眨眼、左上角1/2/3点循环|
|7|running|6|自然交替敲键盘；指任务工作，不是跑步|
|8|review|6|倾斜观察与检查|
|9–10|look|16|顺时针视线，从000到337.5，每22.5度一帧|

没有额外的`thinking`运行时槽位。独立thinking只是附加动画文件，不能据此断言应用会在模型思考时播放。不能断言每次工具调用必触发打字、完成必跳跃、打开窗口必挥手，或16视线必追随鼠标；具体绑定由宿主应用决定。

等待省略号每个点均轻触身体左上沿，不是悬浮效果；没有气泡、连线或额外装饰。独立思考版本有上方分离点，但不作为部署图集使用。

预览GIF的节奏是演示值，不能控制宿主应用的实际播放速度。waiting原生预览192×208，6帧总1330ms；复合全动作预览仅便于观察。
